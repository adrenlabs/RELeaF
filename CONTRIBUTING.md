# Contributing

Thanks for considering a contribution to RELeaF.

- Keep the core usable without a paid AI API or third-party runtime dependency.
- Do not add code that installs or executes the APK/DEX/ELF being analyzed.
- Keep AI integration optional and document local/cloud costs clearly.
- Avoid logging secrets, tokens, or private file contents unnecessarily.
- Include reproducible steps and test output for bug reports.
- Test syntax and smoke checks with Node.js 22+: `npm run check`, `npm test`, and `npm run self-test`.
- Do not submit copyrighted app assets or binaries without permission.

By submitting a contribution, you agree that it may be distributed under the repository's MIT license.
